Mystery Maze: Algorithm Visualization Tool

The "Mystery Maze" project is an interactive application developed in Python using the Tkinter library. It visualizes and compares various pathfinding algorithms, including A*, Breadth-First Search (BFS), Depth-First Search (DFS), and Dijkstra's Algorithm, by solving randomly generated mazes.

Personal Contribution: I was responsible for almost 90% of the work on this project, including algorithm implementation, GUI design, and performance analysis. My role was critical in ensuring the project's success and functionality.

Features

  • Visualization of maze-solving processes for A*, BFS, DFS, and Dijkstra's Algorithm.
  • Interactive GUI allowing users to select algorithms and generate new mazes.
  • Statistical analysis of algorithm performance, including steps taken and accuracy.

Graphical User Interface (GUI)

The application features a user-friendly interface with two main windows:

  • Initial Window: Offers options to start the maze-solving process or exit the application.
  • Main Window: Provides functionalities to generate new mazes, select different algorithms, view statistics, and exit.

Algorithm Implementations

Each algorithm is implemented to solve the maze efficiently:

  • A* Algorithm: Utilizes heuristics to find the shortest path efficiently.
  • Breadth-First Search (BFS): Explores all possible paths level by level to find the shortest path in unweighted graphs.
  • Depth-First Search (DFS): Explores as far as possible along each branch before backtracking, which may not yield the shortest path.
  • Dijkstra's Algorithm: Computes the shortest path in graphs with non-negative weights.

Performance Analysis

The application evaluates each algorithm's performance by measuring the number of steps taken and calculating accuracy based on the optimal solution. Results are displayed in a tabular format for easy comparison.

Running the Project

To run the project:

  1. Install the required dependencies: Pillow, Tkinter, and CustomTkinter.
  2. Navigate to the project directory.
  3. Execute the main script: python src/main.py

Statistics

The application provides detailed statistics, including:

  • Optimal steps for each maze.
  • Steps taken by each algorithm.
  • Accuracy percentages comparing each algorithm's performance to the optimal solution.
