Automated Box Processing Station (V1.0 & V2.0)

Overview

This project focused on solving an automation problem to streamline the box processing workflow. The solution involved designing an automated station that integrates key components, including a weight scale, labeling machine, camera, and display screen, all strategically positioned to maximize efficiency. The station's objective was to enable faster and more accurate box processing while maintaining a user-friendly interface.

Key Features

  • Integrated System: Incorporated critical components like a weight scale, labeling machine, and a camera for streamlined operation.
  • User Interface: Positioned a display screen for easy monitoring and interaction, enhancing usability.
  • Modular Design: Built on an 8020 aluminum extrusion system, ensuring durability, cost-efficiency, and flexibility.

Role & Responsibilities

As the lead Mechanical Designer, I was responsible for:

  • Conceptualizing & Designing: Developed the entire mechanical design of the station, ensuring both functionality and aesthetic appeal.
  • Optimization: Adjusted component placement in Version 2.0 for enhanced efficiency.
  • Supplier Coordination: Identified reliable distributors and managed order preparation to ensure timely delivery for the client.
  • Cost Management: Designed the system using 8020 components to achieve a balance between cost and functionality.

Major Upgrades (V2.0)

  • Optimized Layout: Adjusted the placement of the weight scale, labeling machine, and camera for smoother workflow and better ergonomics.
  • Enhanced Usability: Refined the design for easier access and operation by the end-user.

Technical Details

  • Design Tools: Employed advanced CAD software to create a detailed 3D model and conduct simulations.
  • Materials: Used 8020 aluminum extrusion profiles for a modular, lightweight, and durable structure.
  • Focus Areas: Paid meticulous attention to detail to deliver a station with a unique, polished appearance while ensuring full functionality.

Outcome

While this project is the first of its kind, the station's design is highly functional and ready for implementation. The modular approach ensures adaptability for future upgrades or variations, making it a scalable solution for automation in box processing.
