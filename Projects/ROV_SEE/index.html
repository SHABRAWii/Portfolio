Underwater ROV: Remote Navigation System

This ROV (Remotely Operated Vehicle) was designed for underwater navigation. The system allows real-time remote control and live video monitoring, making it suitable for various underwater exploration and operational tasks.

Personal Contribution

I was responsible for the complete control system, including:

  • Low-Layer Control System: Using Arduino Nano to control the motors and actuators for precise underwater navigation.
  • High-Layer Control System: Implemented using ROS to facilitate remote operation via a joystick.
  • Live Video Feed: Integrated a camera with Raspberry Pi to stream real-time video for monitoring underwater activities.

Key Features

  • Real-time joystick-based control for easy maneuverability.
  • Live camera feed for underwater visualization.
  • Efficient integration of Arduino Nano for motor control and ROS for remote operation.

Technologies Used

  • Arduino Nano for low-level control.
  • ROS (Robot Operating System) for higher-level coordination and communication.
  • Raspberry Pi for camera integration and live video feed streaming.

Project Challenges

  • Ensuring reliable communication between the control layers under water.
  • Achieving precise motor control for stable navigation in an underwater environment.
  • Maintaining a seamless live video feed for monitoring underwater actions.
