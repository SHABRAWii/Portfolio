Vertical Wall-Mounted Plotter for Artistic Creations

This project aimed to create a vertical plotter that could be mounted on a wall with two screws. The system can draw intricate designs from input images, which can be filled with colors to create artistic masterpieces.

My Contributions

As the Software Developer, I worked on:

  • Converting traditional X-Y coordinates into a dual-motor-driven coordinate system.
  • Modifying GRBL firmware to adapt to the new coordinate system and provide real-time feedback.
  • Implementing algorithms for fractional step corrections and feedback-based precision monitoring.
  • Solving complex geometry problems for motor displacement calculations.

Project Workflow

The workflow involved:

  • Processing input images to perform edge detection and convert them into G-code commands.
  • Customizing GRBL code to translate coordinates into motor movements in the new system.
  • Implementing real-time feedback for precise motor control.

Challenges and Solutions

The main challenges involved coordinate system transformations, feedback integration, and handling fractional errors. These were resolved by deeply analyzing and customizing the GRBL firmware, designing correction algorithms, and solving geometry-based problems.

Future Improvements
